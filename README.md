# سامانه مدیریت پروژه‌های بانک سپه

نسخه اولیه شامل صفحه ورود، احراز هویت متصل به دیتابیس D1 و داشبورد مدیریتی RTL است.

## اجرا در VS Code

1. پوشه `F:\sepahbank` را در VS Code باز کنید.
2. ترمینال داخلی VS Code را باز کنید (`Ctrl + ``).
3. برای اولین اجرا دستور زیر را بزنید:

```powershell
npm install
```

4. سپس برنامه را اجرا کنید:

```powershell
npm run dev
```

5. آدرس `http://localhost:3000` را در مرورگر باز کنید.

روش دوم: از منوی `Terminal > Run Task` گزینه `Sepah: Run Development Server` را انتخاب کنید.

## حساب مدیر اولیه

- نام کاربری: `admin`
- رمز عبور: `Admin@123`

دیتابیس محلی در اولین درخواست ورود به‌صورت خودکار ساخته و کاربر مدیر در آن ثبت می‌شود.

## کنترل نسخه تولید

```powershell
npm run build
```
